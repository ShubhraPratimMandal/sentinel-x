# Security Policy

## Scope

SENTINEL-X is a defensive research and security analytics project.

## Responsible Use

Use the platform only with systems, datasets, credentials, and infrastructure you are authorized to analyze.

Do not use this project to:
- gain unauthorized access;
- deploy malware;
- conduct intrusive surveillance;
- evade security controls;
- target real individuals or organizations;
- collect credentials or sensitive data without permission.

## Vulnerability Reports

For security-sensitive findings, create a private responsible-disclosure path when appropriate rather than publishing exploit details in a public issue.

## Secrets

Never commit API keys, passwords, private certificates, cloud credentials, tokens, or production connection strings.

Use environment variables and secret managers instead.
