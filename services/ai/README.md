# AI Analyst Service

The AI layer is an advisory component.

It may:
- summarize supplied evidence;
- extract entities;
- suggest relationships;
- map supplied evidence to ATT&CK techniques;
- identify information gaps;
- draft incident reports.

It must not:
- invent evidence;
- claim unsupported attribution;
- autonomously contact external systems;
- execute offensive actions.

All generated analysis should include confidence and source context.
